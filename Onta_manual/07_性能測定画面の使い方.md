# 7. 性能測定画面の使い方

この章では、性能測定画面を使って「測る」「調整する」「限界を見つける」ための実操作手順を説明します。
各表示項目の意味は、[4. 性能測定画面の説明](./04_性能測定画面の説明.md) を参照してください。

## 7.1 使い始める前の準備

### 7.1.1 測定目的を決める

最初に、何を確認したいかを決めます。

- 周波数特性や歪みを確認したい
  - 基準信号（単音 / スイープ / ノイズ）を使う
- デッキのアジマスを合わせたい
  - 基準信号の中高域トーンとリサージュ表示を使う
- 音多として使える設定上限を探したい
  - 変調タブ（SC数・変調方式）と I-Q を使う

### 7.1.2 配線と入出力を確認する

1. 測定経路を決めます。
   - WAVだけで確認（デジタル経路）
   - 音声入出力で実機を含めて確認（アナログ経路）
2. 音声入出力を使う場合は、送信デバイスと受信デバイスを選択します。
3. レベルが過大にならないよう、送信音量・受信音量を低めから開始します。

## 7.2 基本操作の流れ

性能測定画面は、次の流れで使います。

1. 送信側で信号を選ぶ（基準信号または変調）
2. 送信時間（秒数）と出力先（WAV/音声）を設定する
3. 受信側で入力元（WAV/音声）を設定する
4. 送信と受信をそれぞれスタートする
5. 表示を見ながら条件を調整する
6. 結果を記録する（設定値・観測値・所見）

## 7.3 手順1: 基準信号で測る

### 7.3.1 単音で周波数ごとの状態を見る

1. 送信パネルで「基準信号」タブを選択します。
2. トーン周波数を選びます（例: 1kHz、10kHz、15kHz）。
3. 出力モードを選びます。
   - WAV出力: 出力WAVを作って後で受信
   - 音声出力: 実時間で装置へ送る
4. 受信パネルで入力モードを合わせます（WAVまたは音声）。
5. 受信側を「スタート」、続いて送信側を「スタート」します。
6. FFT・オシロ・周波数カウンタ・THDを確認します。

確認の目安:

- FFTピークが狙い周波数に立っている
- オシロ波形にクリップや大きな歪みがない
- 周波数表示が安定している
- THDが急増していない

### 7.3.2 スイープで帯域の傾向を確認する

1. 送信側で「スイープ（20Hz-20kHz）」を選択します。
2. 受信側を開始してから送信を開始します。
3. FFT表示でレベルが落ちる帯域やピーク/ディップを確認します。

注意:

- スイープ中はワウ表示が更新されません（仕様）。

### 7.3.3 ホワイトノイズで広帯域の癖を確認する

1. 送信側で「ホワイトノイズ」を選択します。
2. 受信側と送信側を開始します。
3. FFTの全体形状を見て、帯域バランスの偏りを確認します。

## 7.4 手順2: アジマスを調整する

1. 送信側で中高域トーン（例: 8kHz または 10kHz）を選びます。
2. 受信側の表示を「リサージュ・ワウ・Fカウンタ」に切り替えます。
3. 再生機側のアジマスを少しずつ調整します。
4. 次を同時に満たす位置を探します。
   - リサージュが対角線に近い
   - 相関が高い
   - ワウ値の揺れが小さい
   - 周波数表示が安定
5. 位置が決まったら、数十秒維持して再現性を確認します。

## 7.5 手順3: OFDM/変調の限界を探る

### 7.5.1 段階的に条件を上げる

1. 送信側を「変調」タブに切り替えます。
2. 低めの条件から開始します。
   - 例: 16-SC + QPSK
3. 受信側で FFT と I-Q を確認します。
4. 問題がなければ段階的に上げます。

- 例: 24-SC + QPSK → 32-SC + 8PSK → 40-SC + 16QAM

5. 点のばらつきや崩れが増えた条件を記録します。

### 7.5.2 限界判定の目安

- 実用に近い条件
  - I-Q の点群が各シンボル近傍にまとまる
  - FFTのサブキャリアが極端に欠けない
- 限界を超えた条件
  - I-Q の点が広く拡散する
  - 群ごとに回転・潰れが目立つ
  - 高域側グループだけ崩れる

注記:

- 56-SC / 64-SC、256QAM は測定用の拡張条件です。
- 通常のメイン画面運用とは分けて評価してください。

## 7.6 おすすめの記録方法

性能測定画面は履歴保存を行わないため、次を手元メモに残す運用を推奨します。

- 測定日時
- デッキ/テープ/接続経路
- 送信条件（信号種別、周波数、SC、変調、秒数、音量）
- 受信条件（入力モード、デバイス、音量）
- 観測結果（FFT傾向、ワウ、周波数、THD、I-Q所見）
- 採用可否（実運用に使う/使わない）

## 7.7 よくある問題と対処

- 周波数表示が安定しない
  - 入出力レベルを下げる/上げる
  - ケーブル接触や接続先を確認する
  - テープ走行が安定するまで待つ
- I-Q が大きく散る
  - 変調を下げる（64QAM -> 16QAM -> 8PSK -> QPSK）
  - サブキャリア数を下げる（40-SC -> 32-SC -> 24-SC）
  - 録再音量を見直す
- ワウが更新されない
  - スイープ/ノイズを使っていないか確認する
  - 単音または変調キャリアで再測定する
- 送受信が始まらない
  - 出力モード（WAV/音声）が有効か確認する
  - WAVファイルやデバイス選択に未設定がないか確認する

## 7.8 最短の実施パターン（迷ったとき）

1. 単音 1kHz でレベルと歪みを確認
2. 単音 10kHz で高域とアジマス傾向を確認
3. 変調 24-SC + QPSK で I-Q のまとまりを確認
4. 問題なければ 32-SC + 16QAM まで上げて限界を探る
5. 安定していた一段下を実運用候補にする
