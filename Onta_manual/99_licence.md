## What the GPL is

The GPL is a free-software license written by the Free Software Foundation.
“Free” here means freedom, not price.
Anyone who receives a GPL-covered program may run it, study it, share it, and change it.

The GPL is a copyleft license.
If you distribute a program covered by the GPL, or a modified version of it, you must pass the same freedoms on to the people who receive it.
You may not add restrictions that take those freedoms away.

## What you must do if you distribute it

Distribution means giving the program to someone else, for example as a download, an installer, or a device that contains the program.
Running the program only for yourself, and keeping your changes private, does not require you to publish those changes.

If you do distribute a GPL-covered program, or a work based on it, you must:

- License that work under the GPL as well. You cannot switch it to a proprietary license.
- Give recipients the complete corresponding source code, or a written offer that makes that source available, in the way the license describes.
- Keep the copyright notices and the license text with the program.
- State clearly if you modified the program.
- Not impose further legal restrictions, such as an NDA or a patent deal that limits the rights the GPL grants.

Object code (a compiled binary) is not a substitute for source.
Source means the preferred form for making modifications.

## Modified versions and combined works

A modified version is still covered by the GPL.
The same is true of a larger program that incorporates GPL-covered code, when you distribute that larger program.
The GPL calls this a work based on the program.
The whole of that distributed work must be available under the GPL.

You may keep separate, independent programs side by side.
Merely shipping them on the same disk does not, by itself, make the other program a GPL work.
Linking GPL code into another program so that they form one program usually does.
The license text draws this line. Read it before combining GPL code with code under another license.
