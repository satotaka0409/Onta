# 6. 履歴画面の使い方

この章では、履歴画面を使って「確認する」「取り出す」「整理する」ための実操作手順を説明します。
各項目の意味は、[3. 履歴画面の説明](./03_履歴画面の説明.md) を参照してください。

## 6.1 基本の使い方

### 6.1.1 画面を開いたら最初に行うこと

1. 「再読込」を押して、最新の履歴を読み込みます。
2. 画面上部のステータス表示で件数を確認します。
   - 受信 n 件 / 送信 n 件 / 不明ブロック n 件
3. 確認したいタブを選びます。
   - 受信履歴
   - 送信履歴
   - 不明ブロック

### 6.1.2 タブごとの見方

- 受信履歴タブ
  - 受信結果、ブロック数、入力種別（Audio/WAV）を確認するときに使います。
- 送信履歴タブ
  - 過去の送信条件（サブキャリア数、変調、mono/stereo）を確認するときに使います。
- 不明ブロックタブ
  - 復元先に紐づけできなかったブロックの発生状況を確認するときに使います。

## 6.2 受信履歴の使い方

### 6.2.1 受信結果を確認する

1. 「受信履歴」タブを開きます。
2. 対象行の「結果」を確認します。
   - COMPLETE: 復元完了
   - IN-COMPLETE: 未完了
3. 必要に応じて「ブロック数」「音声/WAV」「WAVファイル名」も確認します。

### 6.2.2 ブロック明細を確認する

1. 対象行の「受信日時」をクリックします。
2. 行の下にブロック明細（BLK、結果、サブキャリア数、変調、Stereo/mono、ブロックサイズ）が表示されます。
3. もう一度「受信日時」をクリックすると明細を閉じます。

### 6.2.3 復元データをダウンロードする

1. 「ダウンロード」ボタンが表示されている受信行を選びます。
2. 「ダウンロード」を押します。
3. 保存ダイアログで保存先とファイル名を指定します。
4. 画面上部のステータスに保存結果が表示されることを確認します。

注記:

- 行によっては「ダウンロード」ボタンが表示されません。
- これは、履歴データから書き出せるペイロードが無い場合の正常な動作です。

## 6.3 送信履歴の使い方

### 6.3.1 送信設定の再確認

1. 「送信履歴」タブを開きます。
2. 対象行の「サブキャリア数」「変調」「Stereo/mono」を確認します。
3. 必要に応じて「音声/WAV」「WAVファイル名」を確認します。

活用例:

- 受信失敗時に、成功時の送信設定と比較する
- 同じ素材を別条件で送った履歴を見比べる

## 6.4 不明ブロックの使い方

### 6.4.1 発生状況の確認

1. 「不明ブロック」タブを開きます。
2. 「結果」「サブキャリア数」「変調」「Stereo/mono」を確認します。
3. 同時に「ブロック位置」「ファイルハッシュ値」「ブロックハッシュ値」を見て、偏りの有無を確認します。

### 6.4.2 切り分けの進め方

1. 不明ブロックが多い条件を特定します。
2. 送信履歴タブで同時間帯の設定を確認します。
3. 次回送信時は条件を1段下げて比較します。
   - 例: 変調を下げる、サブキャリア数を減らす

## 6.5 履歴削除の手順

履歴削除は、現在選択しているタブの選択行に対して実行されます。

1. 削除したい行を選択します。
2. 「履歴を削除」を押します。
3. 確認ダイアログで内容を確認し、「はい」を選択します。
4. 自動再読込後に、対象行が消えていることを確認します。

注意:

- 削除は取り消せません。
- 削除前に必要なデータは先にダウンロードしてください。

## 6.6 よくある使い方

### 6.6.1 受信失敗の原因を追う

1. 受信履歴で IN-COMPLETE 行を探す
2. 同行のブロック明細を開き、失敗傾向を確認する
3. 不明ブロックタブで同時刻付近の発生有無を確認する
4. 送信履歴で送信条件を確認し、再試行条件を決める

### 6.6.2 成功条件をテンプレート化する

1. COMPLETE の行を複数確認する
2. 共通するサブキャリア数・変調・mono/stereo を抽出する
3. 次回送信の初期設定として採用する

## 6.7 トラブル時の確認ポイント

- 履歴が最新でない
  - 「再読込」を押す
- 「履歴を削除」が押せない
  - いずれかのタブで行を選択してから再実行する
- 「ダウンロード」が表示されない
  - 該当行に書き出し可能データがないため、別の COMPLETE 行を確認する
- 件数が合わないように見える
  - 受信履歴と不明ブロックは別集計なので、両タブを分けて確認する
