# 更新履歴

音多（Onta）の更新内容を、新しい版から順に記録します。

## 1.0.0（2026-09-27）初版

最初の公開版です。ファイル、履歴、ストリーム、性能測定の 4 画面で、カセットテープへ音声として記録し、再生して取り出します。

### ファイル送受信

- ファイルを音声へ変換して送信し、WAV または音声入力から元のファイルを復元します
- サブキャリアは 16〜72、変調は BPSK / QPSK / 8PSK / 16QAM / 64QAM、モノラル / ステレオを選べます
- 同じデータを時間をずらして 2 回記録するインターリーブ（×1 / ×2）。2 回目はサブキャリアと変調を自動で一段下げます
- WAV 出力のサンプリング周波数は 44100 Hz / 48000 Hz / 96000 Hz です。音声出力は、選んだデバイスの周波数へ変換して出します
- 受信は 1 ブロック最大 16,384 バイトです。途中から再生しても、欠けたブロックを後から埋められます
- 全ブロックがそろったとき、出力フォルダーへファイル名で保存します。同名で内容が違うときは番号を付けて残します
- ワウフラッター、エラー率（ビタビ、RS / ターボ）、FFT、I-Q（グループ A〜I の色分け）を受信中に表示します
- 送信詳細と受信詳細で、区間ごとの秒数・サイズ・進捗を確認できます

### 履歴

- 受信履歴、送信履歴、不明ブロックを `Onta_history.bin` に保存します
- 受信が完了したファイルは、履歴画面からダウンロードできます
- ファイルヘッダーを受けずに届いたブロックは不明ブロックに置き、後から同じファイルのヘッダーを受けると受信履歴の明細へ移します

### ストリーム

- 音楽を Opus で圧縮し、ステレオの OFDM でテープへ連続記録します。曲の途中から再生しても受信できます
- 速度は 18Kbps〜50Kbps の 9 段階です。受信側は録音時の速度を自動で検出します
- 入力は WAV / FLAC / MP3、または音声入力です。曲タイトル、アーティスト、ジャケ写を繰り返し記録し、再生すると画面に出します
- テープ速度のずれを推定して補正し、ワウフラッターを表示します

### 性能測定

- 単音（315Hz〜20kHz）、スイープ、ホワイトノイズ、音多と同じ OFDM 波形で、デッキやケーブルの使える範囲を見ます
- 変調は BPSK〜64QAM に加え、性能測定だけ 256QAM を選べます
- FFT、オシロスコープ、リサージュ、周波数カウンタ、歪み率、ワウフラッター、I-Q を表示します。ファイルの保存や履歴には残りません
