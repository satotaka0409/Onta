### About the Screenshots

The screenshots in this manual were taken with the Japanese user interface.
When the Windows display language is not Japanese, or when Onta is started with `--lang en`, it shows English labels (see [1.5 Display Language](./01_what_is_onta.md)).
This manual uses the English labels and gives the Japanese label in parentheses where it helps you match the screenshots.
