# 5. メイン画面の使い方

この章では、メイン画面の操作を「送信」「受信」に分けて説明します。
設定項目の意味そのものは、[2. メイン画面の説明](./02_メイン画面の説明.md) を参照してください。

## 5.1 送信の使い方

### 5.1.1 送信の流れ

送信は次の順で行います。

1. 送信条件を決める（チャンネル / サブキャリア / 変調 / Interleave）
2. 送信元ファイルを指定する
3. 出力先を決める（WAV出力または音声出力）
4. スタートで送信開始、完了後に結果を確認する

### 5.1.2 手順（WAV出力）

1. 送信パネルで以下を設定します。
   - チャンネル
   - サブキャリア
   - 変調
   - Interleave
2. 「送信ファイル」で送信したいファイルを選択します。
3. 出力モードで「WAV」を有効にします。
4. WAV出力先ファイルを指定します。
5. 「スタート」を押します。
6. 完了後、指定した出力先にWAVファイルが生成されていることを確認します。

### 5.1.3 手順（音声出力）

1. 送信パネルで送信条件を設定します。
2. 「送信ファイル」を選択します。
3. 出力モードで「音声」を有効にします。
4. 音声デバイスと音量を設定します。
5. カセットデッキなどへ接続し、録音側を待機状態にします。
6. 「スタート」を押して送信を開始します。
7. 必要に応じて「ストップ」で停止します。

### 5.1.4 送信時のおすすめ設定

- テープ品質やデッキ性能に不安がある場合
  - サブキャリアは小さめ（例: 16-SC, 24-SC）
  - 変調は低め（例: BPSK, QPSK）
- 安定性を優先したい場合
  - Interleave を x2 に設定

### 5.1.5 送信時の注意

- 送信ファイル未指定では開始できません。
- 出力先（WAVまたは音声）が無効だと開始できません。
- 大きいファイルは処理時間が長くなります。

## 5.2 受信の使い方

### 5.2.1 受信の流れ

受信は次の順で行います。

1. 入力モードを選ぶ（WAV / 音声）
2. 入力元（WAVファイルまたは音声デバイス）を指定する
3. 出力フォルダーを指定する
4. スタートで受信開始、結果ファイルを確認する

### 5.2.2 手順（WAV入力）

1. 受信パネルで入力モードを「WAV」にします。
2. 受信対象のWAVファイルを選択します。
3. 出力フォルダーを指定します。
4. 「スタート」を押して受信を開始します。
5. 受信中は進捗表示と受信詳細タブを確認します。
6. 完了後、出力フォルダーに復元ファイルが生成されたことを確認します。

### 5.2.3 手順（音声入力）

1. 入力モードを「音声」にします。
2. 入力デバイスと音量を設定します。
3. 出力フォルダーを指定します。
4. 再生側（カセットデッキなど）を準備して再生を開始します。
5. 「スタート」を押して受信を開始します。
6. 受信が終わったら必要に応じて「ストップ」を押します。

### 5.2.4 受信中の見方

- Progress: 全体の進み具合
- ワウフラッターメータ: テープの揺らぎの目安
- エラーレート表示: 誤り訂正の余裕度の目安
- I-Q表示: 受信点のまとまり具合（広がるほど受信が不安定）

### 5.2.5 受信時の注意

- 出力フォルダー未指定では開始できません。
- WAV入力時は、WAVファイル未指定または未存在だと開始できません。
- WAVファイル選択だけでは受信は始まりません。必ず「スタート」を押してください。

## 5.3 トラブル時の確認ポイント

- 復元に失敗する場合
  - 送信側のサブキャリア・変調を下げて再作成する
  - Interleave を x2 にする
  - 音量が大きすぎる/小さすぎる場合は調整する
- 受信が途中で止まる、進まない場合
  - 入力デバイスの選択ミスがないか確認する
  - 出力フォルダーに書き込み権限があるか確認する
