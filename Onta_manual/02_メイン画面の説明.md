# 2. メイン画面の説明

## 2.1 メイン画面の全体構成

メイン画面は、次の3エリアで構成されます。

1. 送信パネル
2. 受信パネル
3. 詳細タブ（送信詳細 / 受信詳細）

## 2.2 送信パネル

送信パネルは、送信条件の設定と送信開始/停止を行うエリアです。

### 2.2.1 主な設定項目

- チャンネル: モノラル / ステレオ
  - 特に説明は要らないでしょう
- サブキャリア: 16-SC, 24-SC, 32-SC, 40-SC, 48-SC, 56-SC, 64-SC
  - 一度に記録するサブキャリアの数です。片チャンネルあたりの数なのでステレオの場合はこの2倍になります
  - 値が大きい方が1度にたくさんのデータを記録できます
  - しかし、カセットデッキやテープの性能も絡んでくるので、むやみに大きくできません
  - 一般的なラジカセだと 24-SC、高級カセットデッキだと 40-SC 程度が実用域です。56-SC/64-SC は環境依存が大きく、実験的に段階評価してください
- 変調: BPSK, QPSK, 8PSK, 16QAM, 64QAM
  - サブキャリアに記録する変調方式を選択します
  - BPSK(1ビット) -> QPSK(2ビット) -> 8PSK(3ビット) -> 16QAM(4ビット) -> 64QAM(6ビット)
  - 1回の変調で記録できるビット数を決めます。ビット数が大きい方が1度にたくさんのデータを記録できます
  - しかし、カセットデッキやテープの性能も絡んでくるので、むやみに大きくできません
  - 一般的なラジカセだと QPSK～8PSK、高級カセットデッキだと 16QAM 程度が限界と思ってください
- Interleave: x1, x2
  - 同じデータを時間をずらして2回記録するか、1回にしておくかを指定します
  - 1回目でエラーになっても、2回目でリカバリーできる狙いがあります
  - 2回目は信頼性を重視して、自動的にサブキャリア、変調方式をそれぞれ落として記録します
- 入出力:
  - 送信ファイル
    - 送信するファイルを選択します
    - メガバイトを超えるようなデータは、非常に時間がかかります
  - 出力モード（WAV/音声）
    - WAV:WAVファイルを生成します(音声出力とは違って高速に動作します)
    - 音声:パソコンの音声デバイスを使って「音」として出力します
  - 音声デバイス・音量
    - 音声出力するデバイスを指定することができます(実時間で動くので時間がかかります)
  - WAV出力時の出力ファイル
    - WAVファイルの出力先を指定します

### 2.2.2 操作ボタン

- スタート: 送信を開始します。
- ストップ: 送信を停止します。

### 2.2.3 利用時の注意

- 入力ファイル未選択では開始できません。
- 指定した入力ファイルが存在しない場合は開始できません。
- WAV出力または音声出力のいずれかを有効にしてください。

## 2.3 受信パネル

受信パネルは、受信条件の設定、受信開始/停止、受信状態の監視を行うエリアです。

### 2.3.1 上部ステータス表示

- File Name: 受信対象のファイル名
- ファイルサイズ: 受信対象ファイルのサイズ
- ブロック数: 受信対象の総ブロック数
- Progress: 受信進捗

### 2.3.2 主な設定項目

- 入力モード: WAV/音声
  - WAV:WAVファイルを選択します(音声入力とは違って高速に動作します)
  - 音声:パソコンの音声デバイスを使って「音」として入力します
  - 音声入力するデバイスを指定することができます(実時間で動くので時間がかかります)
- WAVファイル（WAV入力時）
  - 入力するWAVファイルを指定します
  - 音声デバイス
- 入力デバイス・音量
  - 音声入力するデバイスを指定することができます(実時間で動くので時間がかかります)
- 出力フォルダー
  - 受信成功した時にファイルを保存するフォルダを指定します

### 2.3.3 可視化エリア

- ワウフラッターメータ（L/R）
  - カセットテープは機械部分があるので、どうしても揺らぎが発生します
  - この揺らぎを可視化したものがワウフラッターメータです
- エラーレート表示
  - エラーの比率をグラフにしたものです
  - 誤り訂正をしているので、エラーがあっても即失敗とはなりません
  - (誤り訂正の状況をグラフ化していると言った方が正確です)
  - ビタビ、RS/ターボ　とあるのは、2つの誤り訂正を組み合わせて使っているためです
  - ヘッダーは ビタビ-RS の組み合わせ
  - データは ビタビ-ターボ の組み合わせです
- FFT表示
  - 送信時は IFFT グラフとして送信時の状況を表示します
  - 受信時は FFT グラフとして受信時の状況を表示します
- I-Q表示
  - I:In-phase(横軸-コサイン波成分) Q:Quadrature(縦軸-サイン波成分) をグラフにプロットすることで
  - どの程度正確に受信できているかを示す表示です
  - サブキャリアのグループによって色分けしています
  - 送信時に選択したサブキャリア数によって、下記のように色分けが決まります

| サブチャンネル選択 | グループ構成    |
| :----------------- | :-------------- |
| SC-16              | A B             |
| SC-24              | A B C           |
| SC-32              | A B C D         |
| SC-40              | A B C D E       |
| SC-48              | A B C D E F     |
| SC-56              | A B C D E F G   |
| SC-64              | A B C D E F G H |

| GROUP | I-Qグラフの色 |
| :---: | :-----------: |
|   A   |      青       |
|   B   |      緑       |
|   C   |      白       |
|   D   |   オレンジ    |
|   E   |      茶       |
|   F   |      紫       |
|   G   |      黄       |
|   H   |      赤       |

### 2.3.4 操作ボタン

- スタート: 受信を開始します。
- ストップ: 受信を停止します。

### 2.3.5 利用時の注意

- 出力フォルダー未指定では開始できません。
- WAV入力では、WAVファイル未選択またはファイル未存在時に開始できません。
- WAVファイルを選択しただけでは受信は始まりません。必ずスタートを押してください。

## 2.4 詳細タブ

受信パネルの下部には、次の2タブがあります。

### 2.4.1 送信詳細

送信時間・サイズ見積り・進捗メーターを確認します。

### 2.4.2 受信詳細

受信処理の項目ごとの結果、サイズ、チャンネル、サブキャリア数、変調、進捗を確認します。
