# 2. メイン画面の説明

## 2.1 メイン画面の全体構成

メイン画面は、次の3エリアで構成されます。

1. 送信パネル
2. 受信パネル
3. 詳細タブ（送信詳細 / 受信詳細）

[スクリーンショット挿入: メイン画面全体]

## 2.2 送信パネル

送信パネルは、送信条件の設定と送信開始/停止を行うエリアです。

### 2.2.1 主な設定項目

- チャンネル: モノラル / ステレオ
- サブキャリア: 8-SC, 16-SC, 24-SC, 32-SC, 40-SC, 48-SC
  - 一度に記録するサブキャリアの数です。片チャンネルあたりの数なので、ステレオの場合はこの2倍になります
  - 値が大きい方が1度にたくさんのデータを記録できます
  - しかし、カセットデッキやテープの性能も絡んでくるので、むやみに大きくできません
  - 一般的なラジカセだと 24-SC 高級カセットデッキだと 40-SC 程度が限界と思ってください
- 変調: BPSK, QPSK, 16QAM, 64QAM
  - サブキャリアに記録する変調方式を選択します
  - BPSK(1ビット) -> QPSK(2ビット) -> 16QAM(4ビット) -> 64QAM(6ビット)
  - 1回の変調で記録できるビット数を決めます。ビット数が大きい方が1度にたくさんのデータを記録できます
  - しかし、カセットデッキやテープの性能も絡んでくるので、むやみに大きくできません
  - 一般的なラジカセだと QPSK 高級カセットデッキだと 16QAM 程度が限界と思ってください
- Interleave: x1, x2
  - 同じデータを時間をずらして2回記録するか、1回にしておくかを指定します
  - 1回目でエラーになっても、2回目でリカバリーできる狙いがあります
  - 2回目は信頼性を重視して、自動的にサブキャリア、変調方式をそれぞれ落として記録します
- 入出力:
  - 送信ファイル
  - 出力モード（WAV出力 / 音声出力）
  - WAV出力時の出力ファイル
  - 音声出力時の出力デバイス・音量

[スクリーンショット挿入: 送信パネル]

### 2.2.2 操作ボタン

- スタート: 送信を開始します。
- ストップ: 送信を停止します。

### 2.2.3 利用時の注意

- 入力ファイル未選択では開始できません。
- 指定した入力ファイルが存在しない場合は開始できません。
- WAV出力または音声出力のいずれかを有効にしてください。

## 2.3 受信パネル

受信パネルは、受信条件の設定、受信開始/停止、受信状態の監視を行うエリアです。

### 2.3.1 上部ステータス表示

- File Name: 受信対象のファイル名
- ファイルサイズ: 受信対象ファイルのサイズ
- ブロック数: 受信対象の総ブロック数
- Progress: 受信進捗

### 2.3.2 主な設定項目

- 入力モード: WAV入力 / 音声入力
- 入力ファイル（WAV入力時）
- 入力デバイス・音量（音声入力時）
- 出力フォルダー

### 2.3.3 可視化エリア

- ワウフラッターメーター（L/R）
- エラーレート表示
- FFT表示
- I-Q表示

### 2.3.4 操作ボタン

- スタート: 受信を開始します。
- ストップ: 受信を停止します。

[スクリーンショット挿入: 受信パネル]

### 2.3.5 利用時の注意

- 出力フォルダー未指定では開始できません。
- WAV入力では、WAVファイル未選択またはファイル未存在時に開始できません。
- WAVファイルを選択しただけでは受信は始まりません。必ずスタートを押してください。

## 2.4 詳細タブ

受信パネルの下部には、次の2タブがあります。

### 2.4.1 送信詳細

送信時間・サイズ見積り・進捗メーターを確認します。

### 2.4.2 受信詳細

受信処理の項目ごとの結果、サイズ、チャンネル、サブキャリア数、変調、進捗を確認します。
