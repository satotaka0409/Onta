# 4. 性能測定画面の説明

## 4.1 性能測定画面の目的

性能測定画面は、カセットデッキやテープ／ケーブル経路の「どこまで使えるか」を見極めるための画面です。
メイン画面のファイル送受信とは別に、次のような確認ができます。

- 単音・スイープ・ノイズで、周波数特性や歪み・ワウフラッターを見る
- 音多と同じ OFDM／QAM 波形を短時間流して、サブキャリアや変調の限界を探る
- FFT・オシロ・リサージュ・I-Q で、信号品質をリアルタイムに監視する

ファイルの送受信・履歴保存は行いません。あくまで測定・調整用です。

## 4.2 画面の全体構成

メイン画面と同様、上段が送信・下段が受信です。タブで上下を入れ替えません。

1. 送信パネル（基準信号／変調の切替）
2. 受信パネル（入力設定と可視化）
3. 可視化タブ（FFT / オシロスコープ / リサージュ・ワウ・Fカウンタ）と I-Q グラフ

画面サイズは 1280 × 1024（既定／最小）を想定しています。

## 4.3 送信パネル

送信パネルでは、測定用信号の種類・長さ・出力先を決めます。

### 4.3.1 基準信号タブ（無変調）

正弦波などの基準信号を出します。カセットやアンプの周波数応答・歪み・ワウ確認の出発点です。

- トーン周波数
  - 315Hz / 400Hz / 1KHz / 3KHz / 8KHz / 10KHz / 12.5KHz / 15KHz / 20KHz
  - 評価したい帯域に合わせて選択します
- スイープ（20Hz～20KHz）
  - 周波数を連続的に動かして、どこまで伸びるかを見ます
- ホワイトノイズ（20Hz～20KHz）
  - 広帯域のノイズを出します。周波数ピークが定まらないため、ワウ計測には向きません
- 音量（縦スライダー）
  - 正弦波振幅（出力レベル）です。過大入力で歪まない範囲に合わせてください

### 4.3.2 変調タブ

音多本体と同じ OFDM マルチキャリア波形を出します。
メイン画面と同等以上の条件を試せるのが特徴です。

- サブキャリア: **16-SC ～ 64-SC**（通常送受信と同じ範囲）
  - 値が大きいほど帯域を広く使い、高域グループ（E/F、さらに G/H）まで載ります
  - デッキやテープの限界を探すときに使います
- 変調: BPSK / QPSK / 8PSK / 16QAM / 64QAM に加え、**256QAM**（性能測定のみ）
  - 多値になるほど密度は上がりますが、ノイズ・歪みに弱くなります
- 送信中も、変調タブでは I-Q グラフが更新されます（コンスタレーションの崩れ具合をその場で確認できます）

| サブチャンネル選択 | グループ構成 |
| :----------------- | :----------- |
| SC-16              | A B          |
| SC-24              | A B C        |
| SC-32              | A B C D      |
| SC-40              | A B C D E    |
| SC-48              | A B C D E F  |
| SC-56              | A … G        |
| SC-64              | A … H        |

| GROUP | I-Qグラフの色 |
| :---: | :-----------: |
|   A   |      青       |
|   B   |      緑       |
|   C   |      白       |
|   D   |   オレンジ    |
|   E   |      茶       |
|   F   |      紫       |
|   G   |      黄       |
|   H   |      赤       |

### 4.3.3 秒数・出力・操作

- 秒数: 30秒 / 60秒 / 120秒
  - 測定時間の長さです。長めに取るとワウやドリフトの様子が掴みやすいです
- 出力モード
  - WAV出力: WAV ファイルを生成します（高速）
  - 音声出力: PC の音声デバイスから実時間で再生します（実機ループバック向き）
- 出力ファイル（WAV 時）・出力デバイス・音量（音声時）
- スタート / ストップ

### 4.3.4 利用時の注意（送信）

- WAV 出力または音声出力のいずれかを有効にしてください。
- 実機で測るときは、送信側デバイスと受信側デバイスの接続（ライン／テープ経路）を先に確認してください。

## 4.4 受信パネル

受信パネルでは、入力経路と可視化の見方を決めます。

### 4.4.1 入力設定

- 入力モード: WAV入力 / 音声入力
- WAV入力時: 入力ファイルを指定
- 音声入力時: 入力デバイス・音量を指定
- スタート / ストップ（送信とは独立して動かせます）

### 4.4.2 可視化タブの切替

L/R の表示は、次のタブで切り替えます。

1. FFT
2. オシロスコープ
3. リサージュ・ワウ・Fカウンタ

右側（または隣接）に I-Q グラフがあります。
**リサージュタブ選択時は I-Q を非表示**にし、代わりにワウ・周波数・歪みの表示領域を広く使います。

### 4.4.3 FFT タブ

- L / R それぞれのスペクトラム（Magnitude dB）を表示します
- FFT サイズ: 1024 / 2048 / 4096
  - 大きいほど周波数分解能は上がりますが、更新は相対的に重くなります
- 窓関数: Hanning / Hamming / Blackman / Flat Top / Rectangular
  - 単音のレベル精度を見たいときは Flat Top、一般観察は Hanning / Hamming が無難です

### 4.4.4 オシロスコープタブ

- AUTO 起立トリガーです（黄線がトリガー時点）
- 縦軸スライダー: 振幅レンジ（おおよそ ±0.1 ～ ±1.0）を L/R 別に変更
- 横軸スライダー: 時間幅（おおよそ 1 ～ 100 ms）を L/R 別に変更
- 「L/R 同期」ON のとき
  - L のレンジ設定を R へコピーし、以降は両チャネルの表示レンジが連動します

波形の歪み・クリッピング・位相同期の崩れを見るのに向いています。

### 4.4.5 リサージュ・ワウ・Fカウンタタブ

ステレオカセットの**アジマス調整**向けの表示です。

- リサージュ
  - L → X 軸、R → Y 軸、±1.0 の正方形
  - 同位相なら対角線（破線ガイド）に乗り、位相差があると楕円になります
  - タイトル付近に相関の目安を表示します
- ワウフラッター
  - L/R 横並びバーメーター（中央が 0、数値付き）
  - 直下に時系列グラフ（タスクマネージャ風）。縦軸は中央 0%・上端 +1%・下端 −1%
  - L=緑系 / R=オレンジ系（FFT と同じ色系統）
  - 約 0.2 秒間隔のスナップショットで更新します
- 周波数カウンタ
  - L/R を 1 Hz 単位で表示します
- 歪み率（THD）
  - L/R を 0.01 % 単位で表示します

#### ワウの測り方（ロック条件）

受信 FFT のピークを、送信側が意図している周波数の最近傍へロックして算出します。

- 基準信号（単音）: 315Hz～20kHz のトーン一覧を基準にロック
- 変調: 選択中サブキャリアの L/R キャリア周波数を基準にロック
- スイープ／ホワイトノイズ: 周波数が動く／広いため、ワウは更新しません

ワウ未ロック時はメーター・時系列を更新しません。

### 4.4.6 I-Q グラフ

- 現在の変調方式に合わせて、BPSK / QPSK / 8PSK / 16QAM / 64QAM / 256QAM の枠が切り替わります
- 受信中（および変調送信中）の全サブキャリア点を描画します
- 点の色はサブキャリアグループ別（A〜H。凡例は性能測定では G/H も表示）

コンスタレーションが広がる・回転する・グループごとに崩れる場合は、その帯域や変調が厳しすぎるサインです。

## 4.5 典型的な使い方

### 4.5.1 デッキの帯域と歪みを見る

1. 送信: 基準信号タブで 1KHz → 10KHz → 15KHz など順に単音を出す
2. 受信: 音声入力でループバックし、FFT でピーク位置・レベル、Fカウンタ／THD を確認
3. 必要ならオシロで波形の歪みを確認

### 4.5.2 アジマスを寄せる

1. 送信: 基準信号で中高域トーン（例: 8KHz / 10KHz）をステレオで出す
2. 受信: 「リサージュ・ワウ・Fカウンタ」タブを開く
3. リサージュが対角線に近づくよう、デッキのアジマスを調整する
4. あわせてワウ・周波数・THD も監視する

### 4.5.3 変調の限界を探る

1. 送信: 変調タブで SC と変調を段階的に上げる（例: 24-SC QPSK → 32-SC 16QAM …）
2. 受信: I-Q と FFT を見ながら、点がまとまる上限を探す
3. 56/64-SC や 256QAM は測定用の拡張条件です。通常のファイル送受信では使いません

## 4.6 メイン画面との違い（要点）

| 項目           | メイン画面              | 性能測定画面                        |
| :------------- | :---------------------- | :---------------------------------- |
| 目的           | ファイル送受信          | 信号品質・限界の測定                |
| サブキャリア   | 8～48                   | 8～48 ＋ 56/64                      |
| 変調           | BPSK～64QAM（8PSK含む） | BPSK～64QAM ＋ 256QAM               |
| エラー率グラフ | あり                    | なし（FFT／オシロ／リサージュ中心） |
| 履歴           | 送受信を保存            | 保存しない                          |

## 4.7 利用時の注意

- 送信と受信は別スタートです。ループバック測定では両方を開始してください。
- スイープ／ホワイトノイズ中はワウ表示が止まります（仕様です）。
- 測定結果は履歴に残りません。条件と所見は別途メモしてください。
- 設定の一部はアプリ設定（`Onta_setting.bin`）に保存され、次回起動時に復元されることがあります。
