Onta Installation

How to install:
  1. Run Onta-install-vX.Y.Z.exe (self-extracting installer, e.g. Onta-install-v1.0.0.exe), choose where to extract, and press "Extract". An Onta folder is created there
  2. Run Install-Onta.cmd in the Onta folder
  3. Choose the display language (日本語 / English). The initial choice is Japanese if Windows is set to Japanese, English otherwise
  4. The setup.exe for your CPU starts. Follow the instructions on the screen

To install manually:
  x64\setup.exe     ... Intel / AMD 64-bit
  arm64\setup.exe   ... Windows on ARM (Snapdragon, etc.)
  (If you run setup.exe directly without choosing a language, Onta follows the Windows display language)

Each folder contains Onta.application and Application Files.
To distribute on a USB drive or shared folder, copy Onta-install-vX.Y.Z.exe, or the whole extracted Onta folder.
